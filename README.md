# Rumbo a las estrellas

Rumbo a las estrellas es un quiz espacial interactivo en español. Responde diez preguntas sobre el espacio, consulta datos breves al terminar cada respuesta y descubre tu puntuación final. La interfaz se adapta al tema claro u oscuro del sistema y respeta la preferencia de movimiento reducido.

## Ejecutar en local

No necesita instalación, dependencias ni servidor. Abre `index.html` directamente en un navegador, también mediante una URL `file://`.

## Publicación

El sitio es estático y se publica en GitHub Pages mediante el workflow **Deploy to GitHub Pages**. Cada pull request hacia `main` comprueba que exista `index.html`; al integrar cambios en `main`, el workflow publica ese archivo.
